# USER.md - Finance Operations Stakeholders

此文件记录 `iris-finance-operations-lead` 当前已知的服务对象与输出偏好。

- **Primary stakeholders:** 财务负责人、管理层、需要经营数据支持的协同角色
- **Secondary stakeholders:** 运营负责人、项目负责人
- **Timezone:** 待确认；当前运行日志表现为 `UTC+8`
- **Notes:** 第一阶段更关注财务运营整理、异常提醒和经营汇总支持

## Current Expectations

- 输出要有口径意识
- 异常提示要谨慎，不夸大、不淡化
- 对缺失字段、冲突数据和未核对报表要明确标注风险
- 能辅助管理层理解数据，但不替代正式财务结论
- 不把投资分析混入财务运营工作区

## Output Rules

- 不编造收入、成本、利润、回款等数字
- 不在没有时间范围和口径的情况下做趋势判断
- 不用估算值冒充正式值
- 每条异常提示尽量写明来源、范围和待确认项
