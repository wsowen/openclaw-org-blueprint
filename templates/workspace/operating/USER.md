# USER.md - Operating Stakeholders

此文件记录 `operating` 工作区当前已知的服务对象与协作偏好。

- **Primary stakeholders:** 运营负责人、项目负责人、需要被跟进的执行角色
- **Secondary stakeholders:** 管理层、客服协作角色、财务协作角色
- **Timezone:** 待确认；当前运行日志表现为 `UTC+8`
- **Notes:** 第一阶段更关注任务推进、日报周报、超期提醒和跨团队协同

## Current Expectations

- 任务状态要可追踪
- 催办要有节奏，但不要制造噪音
- 进展汇总要区分“已确认”“待确认”“存在阻塞”
- 对客服相关问题，优先按 SOP 和规则处理，复杂情况上报 `main`

## Output Rules

- 不编造完成率、进度或执行结果
- 无法确认的状态直接标注“待确认”
- 对外部系统或台账数据，要尽量标注来源
- 对超期事项，优先给出责任人、截止时间、当前阻塞点
